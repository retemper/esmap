# CSS 스코핑

`@esmap/guard`는 마이크로 프론트엔드 간 CSS 누수를 방지합니다.

## 스코프 스타일

CSS 규칙을 MFE의 컨테이너 요소에 자동으로 스코핑하여, 스타일이 호스트나 다른 MFE로 누수되는 것을 방지합니다.

## 글로벌 오염 감지

MFE가 글로벌 스타일(예: `body { ... }`)을 추가할 때 이를 감지하고 개발 환경에서 경고하여, 의도하지 않은 부작용을 조기에 발견할 수 있도록 합니다.
